# Full-grid ownership; Settler cut for v1

We considered giving the player a small starting claim expanded over time via Settler units, matching the GDD's stated unit roster (§6: Settler, Soldier, optional Trader). We chose full 8x8 ownership from turn one instead, for simplicity. This leaves Settler with no job, so it's deferred for v1 alongside Trader — Soldier is the only unit type implemented.
